# Canonical Rule Matrix - Step 18

This registry gives every active mechanical procedure in **Uchronies & Treasures Large** one stable canonical home. The code is the durable reference; page numbers may change during layout.

## Editorial contract

- **RULE** entries are authoritative. A later chapter may summarize or point back to a RULE, but must not silently redefine it.
- **PRINCIPLE** entries explain adjudication philosophy without creating a second mechanical rule.
- **EXAMPLE** entries demonstrate application and never create exceptions by themselves.
- **WARNING** entries isolate irreversible thresholds, limits, or easy-to-miss exceptions.
- Any future change to a RULE must update its canonical source, `_data/rules.yml` when numeric data are involved, relevant consistency tests, and this registry in the same commit.
