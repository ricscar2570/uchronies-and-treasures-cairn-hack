# STEP22 Blind Lookup Test Protocol

Use one Warden who has not read an earlier edition. Do not coach during the test. Record time, first page opened, pages traversed, search use, answer, and error.

## Lookup tasks
1. What happens when contamination reduces WIL to 0?
2. How does focused fire work?
3. When is a Site Check made?
4. When does the contamination clock reset?
5. How is retreat resolved?
6. How is an unpaid expense financed?
7. How is a Zhou Claim recorded?
8. How does an agent earn qualifying-operation credit?

## Acceptance targets
- Simple rule: <=30 seconds.
- Complete procedure: <=90 seconds.
- Cross-reference: <=2 minutes.
- Ordinary individual settlement: <=3 minutes.
- Quick Settlement for five agents: <=15 minutes.
- Essential bookkeeping update: <=5 minutes.
- Standard bookkeeping update: <=12 minutes.

A human result is required. Do not infer PASS from automated tests.
