# Uchronies & Treasures — Omnibus Edition QA Report

## Scope

The Omnibus profile combines every unique reader-facing component of the Step 22 publication line in one A5 two-column book. The Operational profile is not appended as a duplicate copy of the same rules. Its substantive content is already represented by the core chapters, full adventures, full Example of Play, and table tools included in the Omnibus.

## Step 22.1 consistency corrections incorporated

Before composing the Omnibus:

1. Information Layer terminology was unified to Immediate / Professional / Examined / Contested / Absent in the Warden Cheat Sheet and Mission Worksheet.
2. The Warden Cheat Sheet Adjudication Ladder was aligned to the canonical six-step version and now includes Blocked or impossible.
3. Starting-package inventory wording was narrowed so that slot exemption cannot be misread as a general rule for later equipment.
4. Chicago Loop Local Event result 1 no longer creates an accidental second route change.
5. Deterioration 3 now explicitly applies the harsher-zone scheduled-contamination timing rule.
6. The Meridian Operations Sheet now includes an Occupied now? field.
